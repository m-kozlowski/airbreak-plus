Steps To Create An Airbreak Plus Development Environment In Windows And Build The Patched Binaries
##################################################################################################

To install Windows Subsystem For Linux (WSL2) in Windows, open the PowerShell console as an Administrator by right-clicking on the 'Start' button and selecting 'PowerShell (Admin)' and once open type :

    wsl --install


Reboot Windows. If you don't know how then you shouldn't be reading these instructions.


Once WSL2 is set up and you have rebooted your Windows OS open the PowerShell console as an Administrator by right-clicking on the 'Start' button and selecting 'PowerShell (Admin)'.
When the Administrative PowerShell console opens, type in this command to get WSL2 started:

    wt wsl

Then hit return. Do not close the Administrative PowerShell console yet.

Once the WSL2 terminal window opens, update and upgrade WSL2, by typing the following from the command prompt in WSL2 :

    sudo apt update

Then press 'return'

Once the update process completes, then type :

    sudo apt upgrade

Then press 'return'.

Once all of the updates and upgrade packages have been downloaded and installed and the WSL2 command prompt returns, reboot WSL2 by first typing the following into the Administrative PowerShell console :

    wsl --shutdown

Then press 'return'.

Once the WSL2 console is closed and shut down, then type the following into the Administrative PowerShell console (One of the commands will error, one will work, it depends on your build of Windows) :

    Get-Service LxssManager | Restart-Service
    Get-Service WSLService | Restart-Service

Then press 'return'.

To to restart the WSL2 console again, type the following command from the PowerShell Administrative command prompt and then press 'return' :

    wt wsl

Once the WSL Console is back up again, type the following lines one at a time into the WSL2 console, hitting 'return' after each line, enntering your user password as required, and waiting for each software installation to complete :  

    sudo apt install openocd 
    sudo apt-get install python3-pip
    sudo apt install gcc-arm-none-eabi

Once the software installation is complete, in the WSL2 console type these lines hitting 'return' after each one :

    cd
    mkdir git
    cd git

The first makes sure you are in your 'home' directory, the second line creates a folder to store the required GitHub repository 'Airbreak plus' files, and the 3rd line switches to that directory.

Then, clone the required 'AirBreak Plus' repository by typing the following command in the WSL2 console and pressing 'return':
    
    git clone https://github.com/m-kozlowski/airbreak-plus

Once it has cloned the repository, switch to the direcectory by typing the following command and then pressing 'return' :

    cd airbreak-plus

Then, from Windows Explorer, copy the original UNMODIFIED ResMed firmware binary you want to patch to the WSL2 "airbreak-plus" folder. It MUST have the name 'stm32.bin'. In Windows Explorer, the WSL2 filesystem shows up as 'Linux' and you can navigate to the correct folder which will be the following path but with your User Name :

    \\wsl.localhost\Ubuntu\home\(Your User Name Here)\git\airbreak-plus
 
Copy the original 'stm32.bin' file to that path.

Then, from the WSL2 console from within the 'airbreak-plus' folder, type :

    mkdir build

This might error if the 'build' path already exists, but this is fine.

Then, to make sure the build environment is clean and build the patched Resmed binaries, type the following command in the WSL2 console and then press 'return' : 

    make clean && make
    
This will make the various ResMed Binaries.
Once this process is complete, you can find all the various patched binaries in the 'build' directory.
You can switch to the 'build' directory by typing the following command in the WSL2 console and then pressing 'return' :

    cd build

You can list the files in this directory by typing the following command in the WSL2 console and then pressing 'return' :

    ls

You can also access this directory from Windows Explorer to retrieve the binaries using the following path (substituting your username) :

    \\wsl.localhost\Ubuntu\home\(Your User Name Here)\git\airbreak-plus

########################################

If the Airbreak Plus Git repository is updated and you want to download the latest fixes and/or patches and re-make the binaries, you simply need to type (from the 'airbreak-plus' folder in WSL2) :

    git pull https://github.com/m-kozlowski/airbreak-plus

This downloads the latest version of all the files.
Then from the same 'airbreak-plus' folder in WSL2, type the following as before in the WSL2 console and pressing 'return' to rebuild the ResMed Binaries :

    make clean && make

This clears everything from the 'build' directory and recreates the binaries using the latest Airbreak Plus patching information.
